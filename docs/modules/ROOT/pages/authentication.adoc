= Authentication Modes & Keycloak SSO
:toc:

The OCSP Responder and Admin Console (`http://localhost:3002`) support dual authentication modes bound via `AppSecurityProperties` (`security.auth-mode`), `AdminProperties` (`admin.*`), and `KeycloakProperties` (`keycloak.*`).

== Configurable Authentication Mode

In `ocsp-responder/src/main/resources/application.yml` and `application-dev.yml`:

[source,yaml]
----
security:
  auth-mode: ${AUTH_MODE:KEYCLOAK} # KEYCLOAK or SELF_MANAGED
----

[cols="1,2,2", options="header"]
|===
| Dimension | `KEYCLOAK` Mode | `SELF_MANAGED` Mode

| *Identity Provider*
| Centralized Keycloak IAM Server (`http://localhost:8081`)
| In-memory BCrypt Spring Security user (`AdminProperties`)

| *Primary Auth Flow*
| OpenID Connect SSO redirect to `http://localhost:3002/login`
| Username/password form login on `http://localhost:3002/login`

| *Token Type*
| Signed RS256 JWT Bearer Token (`Authorization: Bearer ...`)
| Basic Auth (`Authorization: Basic ...`)

| *Role Mapping*
| `KeycloakJwtAuthenticationConverter` maps realm roles & groups to `ROLE_ADMIN`
| Built-in `ROLE_ADMIN`

| *Break-Glass Fallback*
| Supported (HTTP Basic Auth username & password remain active)
| Built-in username & password
|===

== Keycloak OIDC Configuration (`keycloak/realm-export.json`)

The Keycloak container (`ocsp-keycloak`) runs on port `8081` and imports `keycloak/realm-export.json`:

* **Realm**: `incert`
* **Client ID**: `ocsp-console`
* **Allowed Redirect URIs**:
  - `http://localhost:3002/*`
  - `http://127.0.0.1:3002/*`
  - `http://localhost:3000/*`
  - `http://127.0.0.1:3000/*`
* **Web Origins**: `*`
* **Default Users**:
  - `admin` / `changeme` (group `ocsp-administrators` -> `ROLE_ADMIN`)
  - `operator` / `operator123` (group `ocsp-operators` -> `ROLE_ADMIN`, `ROLE_OPERATOR`)
  - `auditor` / `auditor123` (group `ocsp-auditors` -> `ROLE_AUDITOR`)

=== Single Sign-On (SSO) Flow on Port `3002`

1. Operator opens `http://localhost:3002/login`.
2. `ocsp-console` queries `GET /api/v1/auth/config` and receives `authMode: "KEYCLOAK"`.
3. Clicking **Sign in with Keycloak SSO** redirects the browser to:
   `http://localhost:8081/realms/incert/protocol/openid-connect/auth?client_id=ocsp-console&redirect_uri=http%3A%2F%2Flocalhost%3A3002%2Flogin&response_type=token&scope=openid%20profile%20email`
4. After authenticating (`admin` / `changeme`), Keycloak redirects back to `http://localhost:3002/login#access_token=...`.
5. `AuthContext.js` extracts the JWT access token, verifies it via `GET /api/v1/auth/me`, and navigates to `/dashboard`.
