= Docker Deployment & Compose
:toc:

The Incert OCSP Subsystem is containerized with Docker Compose (`docker-compose.yml`), providing single-command orchestration and healthcheck gating across all 7 OCSP containers (plus the companion `kms-simulator` stack).

== Quickstart

To build and deploy all services in detached mode:

[source,bash]
----
docker compose up -d --build
----

To verify that all containers are running and `healthy`:

[source,bash]
----
docker compose ps
----

[IMPORTANT]
.Updating Keycloak Realm Configuration (`keycloak/realm-export.json`)
====
Keycloak runs with `start-dev --import-realm`, which only imports `realm-export.json` when the container's H2 storage is initialized. Whenever `keycloak/realm-export.json` is modified, recreate the Keycloak container so the updated realm is imported:
[source,bash]
----
docker compose up -d --force-recreate keycloak
----
====

== Deployed Containers (`OCSP` Stack)

[cols="2,2,1,3", options="header"]
|===
| Service | Container Name | Host Port(s) | Role

| `mariadb`
| `ocsp-mariadb`
| `3307` (`-> 3306`)
| MariaDB 10.11 storing `revocation_status`, `inbox_event`, and `signing_certificates`.

| `rabbitmq`
| `ocsp-rabbitmq`
| `5671`, `5672`, `15672`
| RabbitMQ 3.13 broker with strict mTLS on `5671`, plaintext on `5672`, and Management UI on `15672`.

| `hsm`
| `ocsp-hsm`
| Internal volume
| Dedicated SoftHSM2 PKCS#11 container initializing the empty `ocsp-signing` token.

| `keycloak`
| `ocsp-keycloak`
| `8081`
| Keycloak 24.0 IAM server importing the `incert` realm (`http://localhost:3002/*` redirect URIs).

| `ocsp-responder`
| `ocsp-responder`
| `8080`
| Spring Boot RFC 6960 responder, SoftHSM2 PKCS#11 multi-CA signer, RabbitMQ listener, and Admin API.

| `ocsp-client`
| `ocsp-client`
| `8082`
| Standalone RFC 6960 / RFC 8954 client and web test harness with Issuer CA PEM verification.

| `ocsp-console`
| `ocsp-console`
| `3002` (`-> 80`)
| Plain JavaScript (`.js`) React 18 + Mantine v7 Admin Console served via Nginx.
|===

== Companion KMS Simulator Containers (`kms-simulator` Stack)

[cols="2,2,1,3", options="header"]
|===
| Service | Container Name | Host Port(s) | Role

| `kms-mariadb`
| `kms-mariadb`
| `3308` (`-> 3306`)
| MariaDB 10.11 storing `certificate_authority`, `certificate`, and `outbox_event`.

| `kms-simulator`
| `kms-simulator`
| `8090`
| CA creation engine, CSR certificate issuance (`OCSP_SIGNING`, `SERVER_TLS`, `CLIENT_TLS`), revocation, 2s Outbox relay, and 3s Outbox manifest / replay service.

| `kms-console`
| `kms-console`
| `3001` (`-> 80`)
| React 18 KMS Operator UI (`/cas`, `/certificates`, `/outbox`).
|===
