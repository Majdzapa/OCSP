= Incert OCSP Subsystem 2.0
:description: High-performance, RFC 6960-compliant Online Certificate Status Protocol (OCSP) Responder
:keywords: ocsp, pki, rfc6960, cryptography, hsm, pkcs11, rabbitmq, mtls, keycloak

Welcome to the official documentation for the **Incert OCSP Subsystem**. This solution provides an enterprise-grade, high-throughput RFC 6960-compliant Online Certificate Status Protocol (OCSP) responder designed for zero-trust public key infrastructures (PKI).

== Highlights & Capabilities

[cols="1,3"]
|===
| Feature | Description

| *RFC 6960 Conformance*
| Full compliance with RFC 6960 standard, supporting both HTTP POST (binary DER) and HTTP GET (base64url) queries, with mandatory cryptographically secure Nonce echoing.

| *Hardware Security Module (HSM)*
| Signing private keys are managed exclusively inside a SoftHSM2 PKCS#11 hardware container. Keys are marked non-extractable, ensuring zero private key material ever touches the responder application filesystem or memory.

| *Strict Mutual TLS (mTLS)*
| All inter-service messaging between KMS Simulator, RabbitMQ, and the OCSP Responder communicates over mutual TLS (port `5671`) with strict CA peer certificate verification (`fail_if_no_peer_cert = true`).

| *Dynamic Signing Certificate Rotation*
| Instant, zero-downtime signing certificate rotation. The administrator can enroll certificates via PEM or API and switch active keys in-memory on the PKCS#11 signer without container restarts.

| *Dual-Mode Authentication*
| Supports both `KEYCLOCK` (OAuth2 / OpenID Connect SSO redirect, pre-configured realm, groups, and JWT Bearer tokens) and `SELF_MANAGED` (BCrypt credentials and admin `X-API-KEY`).

| *Configurable TLS Toggles*
| Runtime and property-driven activation/deactivation toggles for both RabbitMQ messaging TLS and OCSP login TLS.

| *Modern Web Console*
| Full-featured React 18 / Mantine v7 single-page application (`ocsp-console`) with live metrics, audit trail, certificate revocation actions, and signing key management.
|===
